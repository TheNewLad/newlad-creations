description: "The part of building software that keeps pulling me back."

I took a computer science class in 2011 and started writing Java. I've been writing code ever since.

These days, I especially enjoy frontend development. I like being able to change something and see the result right away. That instant feedback makes building feel tangible.

Design is a different challenge for me. I can recognize a design I like, but visualizing it from scratch is harder. I'm a visual person, so having something in front of me to react to helps.

I enjoy engineering solutions and figuring out how to make things work. Frontend gives me a way to see that process happen.
